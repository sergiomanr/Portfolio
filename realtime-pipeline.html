Real-Time Processing Pipeline

Ride-Sharing Data Lakehouse

Work About Me

Project Overview

An end-to-end data pipeline implementing a Medallion Architecture (Bronze, Silver, Gold layers) using PySpark, Delta Lake, and MinIO (S3-compatible storage). The pipeline supports real-time event streaming via Kafka (Redpanda), orchestrated by Apache Airflow, with aggregated business metrics exported to a PostgreSQL database for reporting and visualized via Grafana and a client-side analytics dashboard.

Architecture

Key Features

  • Medallion Lakehouse Pattern: Progressive data processing stages: raw JSON events in Bronze, cleaned schema-enforced Delta Lake tables in Silver, and daily aggregated business KPIs in Gold.
  • Kafka / Redpanda Event Streaming: Simulates real-time ingestion. A producer publishes JSON ride records to a Redpanda topic, and a consumer aggregates them into batch Gzip files, writing to the Bronze layer with manual offset commits.
  • PostgreSQL & Grafana Integration: Daily metrics from the Gold Delta Lake table are exported to a PostgreSQL instance, enabling direct SQL querying and visualization within Grafana.
  • Incremental Streaming Pipeline: PySpark Structured Streaming with checkpoints for incremental updates from the Bronze path to the Silver Delta Lake table using the availableNow=True trigger.
  • Containerized Local Stack: A unified Docker Compose environment comprising Redpanda, Redpanda Console UI, MinIO storage, PostgreSQL, and Grafana.
  • Modern Python Tooling: Dependency management and execution handled via uv and pyproject.toml.
  • Airflow Orchestration: A DAG schedules and coordinates pipeline task dependencies at regular intervals.

Pipeline Flow

The data flows through six distinct stages: NYC taxi trip data is downloaded from HuggingFace, streamed through Kafka/Redpanda, persisted as compressed JSONLines in the Bronze layer, cleaned and validated into Silver Delta Lake tables via Structured Streaming, aggregated into Gold-layer metrics (revenue, rides, distance, active drivers), exported to a PostgreSQL database, and rendered on a responsive analytics dashboard and Grafana.

Technical Stack

  • Engine: PySpark with Delta Lake for lakehouse storage.
  • Event Broker: Redpanda / Apache Kafka for real-time event streaming.
  • Cloud Storage: AWS S3 or local MinIO (S3-compatible).
  • Relational Database: PostgreSQL for structured reporting.
  • Visualization: Grafana & Chart.js for real-time metrics dashboards.
  • Orchestration: Apache Airflow 2.8+ for DAG scheduling and dependency management.
  • Modern Tooling: uv for package/dependency management.
  • Containerization: Docker Compose for the full local infrastructure stack.
