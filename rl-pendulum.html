Project Overview

This project demonstrates the training and deployment of deep reinforcement learning policies to solve classic chaotic control tasks: balancing double and triple pendulums on an unactuated track. The models run entirely client-side in the browser using custom JS physics and neural network inference engines.

What is Reinforcement Learning?

Reinforcement Learning (RL) is a paradigm of machine learning where an autonomous agent learns to achieve a complex goal in an environment by receiving numeric rewards or penalties. Unlike supervised learning, which trains models using static datasets of pre-defined correct outputs, an RL agent learns entirely through trial-and-error.

The agent monitors the environment's current state, selects an action, experiences the environment's state transition, and receives feedback. Over millions of iterations, it optimizes a mathematical policy to maximize the expected cumulative reward over time.

How the Model Works

To balance multiple unactuated pendulum joints, the agent must perform a highly coordinated sequence of maneuvers:

  • Observation Space: At each 20ms step, the agent reads the system telemetry: cart displacement/velocity, and relative angles/angular velocities of all links.
  • Action Space: The policy outputs a continuous value mapping to a force applied directly to the cart (up to $\pm 500$ Newtons).
  • minGRU Recurrence: The controller utilizes a Minimal Gated Recurrent Unit (minGRU) layer. This gives the network sequence-based memory, allowing it to estimate system velocities and anticipate delayed swingup momentum.
  • Generalization Test: Adjusting gravity or friction sliders tests the agent's zero-shot generalization under conditions it never experienced during training.

Technical Stack

  • Deep RL: Trained using Proximal Policy Optimization (PPO) and minGRU recurrent cells in Python and PyTorch.
  • Lagrangian Physics Solver: Equations of motion derived symbolically using SymPy and integrated in JS using Runge-Kutta 4th order (RK4) integration.
  • Vanilla JavaScript Inference: Weights exported into flat binary arrays (`Float32Array`) and computed client-side with no external libraries.
