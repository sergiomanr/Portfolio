Project Overview

This project features the real-time deployment of deep reinforcement learning agents capable of solving highly non-linear control tasks: swinging up and stabilizing multi-link pendulums on an unactuated cart. All inference runs entirely client-side in the browser using a hand-rolled neural network runtime.

Ongoing Research: Training is currently active on a quadruple pendulum (4-link) controller. The four-link system presents an order-of-magnitude increase in chaotic coupling and state-space complexity compared to the triple pendulum, and stabilizing it remains an open challenge.

How the Model Works

At each 20 ms step the agent observes cart position/velocity and the relative angle and angular velocity of every link, then outputs a single continuous force applied to the cart (±20 N). A minGRU recurrent layer gives the network memory across timesteps, which is essential for building swing-up momentum before balancing becomes possible.

Technical Stack

  • PPO + minGRU: Trained with Proximal Policy Optimization using a recurrent minGRU actor-critic. The value network shares the recurrent trunk with the policy; advantages are computed via GAE(λ) with a clipped surrogate objective. The environment runs in MuJoCo with a continuous action space and shaped cosine reward per link.
