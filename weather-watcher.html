Project Overview

Weather watcher is an analytics dashboard that bridges the gap between urban data and personal fashion. By utilizing public traffic cameras from the Portal de Datos Abiertos del Ayuntamiento de Madrid, the system provides almost real-time insights into what people are actually wearing on the streets.

Technical Stack

  • Computer Vision: Ultralytics YOLO for person detection and localization.
  • AI Analysis: OpenAI GPT-4o for fine-grained clothing classification and trend analysis.
  • Backend: Flask for data orchestration and API serving.
  • Frontend: Leaflet for interactive map visualization of Madrid's districts.

The Problem

Deciding what to wear often involves checking the weather, but weather alone doesn't tell you how people are dressing for it. Weather watcher solves this by providing a "visual temperature" of the city.
